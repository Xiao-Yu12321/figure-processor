# 几何截图工坊

阈值去灰、背景透明化和边缘平滑现已接入后端网页的“线稿净化”模式，也可运行[独立小实验](experiments/README.md)。默认仍为基础增强，手动上传和豆包流程均保留。

截图上传 / 拖入 / 剪贴板粘贴 → 后端清晰化 → 去除纯色背景 → 自动裁边 → 下载透明 PNG。前端只负责文件上传、参数、预览和下载，服务器模式全部计算在 Python 后端完成。

## Mac / Linux 启动后端版

需要 Python 3.12。终端进入解压后的项目目录后执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python model_assets.py
.venv/bin/python app.py
```

在同一台电脑的浏览器访问端口 5000。源码包包含已校验的 FSRCNN 权重；下载命令在权重有效时直接复用，不重复联网。服务启动后必须通过它提供的页面使用 AI 功能，双击 HTML 只能使用离线基础版。公网部署请使用生产 WSGI 服务并配置访问控制；API 付费能力不应暴露给未授权用户。

## 清晰化方式

| 模式 | 实现 | 是否发送图片给第三方 |
| --- | --- | --- |
| 基础增强 | Pillow Lanczos 放大、可选降噪、非锐化掩模 | 否 |
| 线稿净化 | 亮度阈值去灰、背景透明、蒙版边缘平滑、指定单色线条 | 否 |
| 本地模型 FSRCNN | 下载好的 FSRCNN x2 预训练权重，OpenCV CPU 分块推理 | 否 |
| 豆包 API | 火山方舟 Seedream 图片编辑接口 | 是，发送至火山引擎 |
| 豆包 App（Windows 自动操作） | 本机粘贴图片与指令、右键复制生成图 | 是，通过你已登录的豆包客户端 |

本地模型原生放大 2 倍，再适配选择的最终尺寸，不会再次叠加所选倍数。所有模式在清晰化后去背景、裁边并生成透明 PNG。AI 模式保留原有透明通道，原图最多 100 万像素。本地模型改用轻量 FSRCNN，权重约 38 KB，随 GitHub 源码一起提供，原有 EDSR 权重可保留但不再加载。基础增强和本地模型以 10 秒内完成为目标，超过 10 秒前端会报超时；取消等待不代表服务器计算停止。豆包为外部服务，无法承诺 10 秒完成，单独保留最多 180 秒等待。本地模型同一时间仅处理一个请求，其他请求收到忙碌提示。

FSRCNN 和豆包均不保证数学符号绝对准确，应核对字母、虚线和角度标记。尤其豆包是生成式图片编辑，并非严格保真的超分模型。

## 网页线稿净化

启动 `app.py` 后，在浏览器选择“线稿净化 · 去灰与平滑”。上传、拖入或粘贴截图，可先框选，再设置：

- 去灰阈值：默认 170，范围 0–254。调低去除更多灰色；浅色字母或虚线消失时调高。
- 边缘平滑：默认 0.5，范围 0–2，0 关闭。仅平滑透明边缘，不重画几何结构。
- 线条颜色：默认黑色，可选择一个主体颜色；目前不是自动保留多种原始颜色。

点击处理后仍可框选保留结果，并下载透明 PNG。此模式由后端计算，不调用 AI、API 或豆包客户端；灰度相近的灰块和浅线可能无法分开，需要结合真实截图调节。为避免重复处理，此模式隐藏原有背景容差、锐化和降噪控件，保留原图放大倍数和透明边距。返回其他模式时原控件与设置恢复。

双击打开的独立 HTML 仍为基础版；线稿净化需通过 Python 后端网页使用。源码包包含 `experiments` 中的复用算法，不包含该目录的运行输出。

## 框选保留区域

- 处理前：上传后点击原图下方“框选处理区域”，在图上拖拽，再点击“处理图片”。只对选区进行清晰化、去背景和裁边；“取消选区”恢复处理完整原图。
- 处理后：点击结果下方“框选保留区域”，拖拽后点击“保留选区”。下载按钮会保存裁剪后的透明 PNG；“取消选区”只撤销尚未应用的选框，“恢复完整结果”可恢复本次处理得到的完整图片。
- 可以重新拖拽或反向拖拽选择区域，按 Escape 取消当前选框。预览缩放或窗口大小变化不改变实际图片选区坐标。
- 后端版两种裁剪都在 Python 中完成，前端只记录选区。结果裁剪不会重新运行模型或调用付费 API。原图整体仍需符合 1200 万像素和 20 MB 上传限制，本地 AI 的 100 万像素限制按选区计算。
- 离线基础 HTML 同样支持前后框选，在浏览器本地完成裁剪。

## Windows 豆包 App 自动操作（无需 API）

此模式模拟你在 Windows 客户端中的操作：粘贴图片 → 粘贴固定清晰化指令并发送 → 等待 → 右键生成图 → 复制图片 → 剪贴板取回 → 系统去背景、裁边。不会使用豆包 API，也不需要 API Key。

这是需要在真实客户端校准的桌面自动化初版。云端 Linux 无法验证实际 Windows App 的菜单、焦点切换和布局，已有自动化测试只验证适配逻辑和接口，并不代表客户端真实流程已跑通。首版按固定间隔等待（默认 60 秒），没有自动识别生成完成，不能保证完整流程小于 10 秒。

### 首次安装与校准

先停止旧的 app.py（Ctrl+C），更新 GitHub 代码。用 PowerShell 运行：

```powershell
cd D:\figure_process
.\.venv\Scripts\python.exe -m pip install -r requirements-windows.txt
.\.venv\Scripts\python.exe desktop_automation.py calibrate
```

在豆包中保持登录，打开专用清晰化会话，保留一张已生成的示例图，输入框留空。每次在终端按 Enter 后，有 5 秒切回豆包，将鼠标放在指定点，脚本自动记录相对坐标：

1. 底部消息输入框中心。
2. 最新生成图片的缩略图中心，不是上传的原图。
3. 右键该生成图之后的“复制/复制图片”菜单项中心。此步骤只停留鼠标，不点击菜单项。

第三步按 Enter 后需要切回豆包、重新右键打开菜单，再将鼠标移至复制项。校准时应保持豆包为普通用户运行，所有目标点都在窗口内。校准结束关闭菜单，回到该会话底部。配置保存在本地 `.doubao-desktop.json`，不会上传 GitHub 或打入源码包。可编辑其中的 `generation_wait`（15–240 秒）、`attachment_wait`（2–30 秒）和 `prompt`。不同输入导致生成图位置明显变化时，需要重新校准生成图和菜单坐标。

只检查窗口是否匹配，不发送内容：

```powershell
.\.venv\Scripts\python.exe desktop_automation.py check
```

校准后先测试右键复制，不上传、不发送消息：

```powershell
.\.venv\Scripts\python.exe desktop_automation.py test-copy
```

脚本会右键现有的生成图并复制。切回我们的网页按 Ctrl+V，核对是不是期望的那张图；复制验证通过后，再启用完整自动发送流程。

### 启用与使用

```powershell
$env:DOUBAO_DESKTOP_ENABLED = '1'
.\.venv\Scripts\python.exe app.py
```

打开同一台电脑的 `http://127.0.0.1:5000`，选择“豆包 App · Windows 自动操作”，上传或框选原图，点击“处理图片”。豆包生成图按原尺寸导回，不额外拉伸或放大；处理结果可继续框选保留，并下载透明 PNG。

- 需要交互式 Windows 桌面；保持豆包窗口打开，窗口大小、侧栏布局、会话和显示缩放与校准时一致。窗口移动允许，尺寸和身份不匹配时停止。
- 运行期间不要使用键盘、鼠标或剪贴板。脚本会覆盖剪贴板内容；将鼠标移到屏幕角落可紧急停止。出现登录/验证码需手动处理，再重新校准或测试；不会绕过验证。
- 脚本只发送一次，不自动重试。等待时间不够、右键位置失效或复制到文本/链接时会失败。只接受本次更新后的剪贴板图片，不读取旧剪贴板图片；如果复制的内容与输入像素完全相同也会拒绝。
- 坐标式自动化不能完全确认图片的语义归属，第一次必须用一张容易辨认的测试图核对是否拿到本次生成结果。生成图的位置或形状变化可能导致错误，需调整校准或改为手动复制后粘贴上传。
- 脚本结束后尝试切回浏览器；若 Windows 阻止切换，手动回到浏览器查看结果。超时或紧急停止后先检查豆包聊天状态，避免再次点击造成重复发送。
- 仅允许本机访问触发该功能，并检查浏览器来源；不接受局域网或其他网站发起的桌面操作。无需为此配置 API 密钥。

## 配置豆包 API

在火山方舟控制台开通支持图片编辑的 Seedream 模型，获取 API Key 和实际模型 ID。普通豆包聊天模型 ID 不适用。后端读取：

- `ARK_API_KEY`：密钥，仅在服务器环境中保存；不要放到前端、源码、截图或聊天中。
- `ARK_IMAGE_MODEL`：控制台提供的图片编辑模型 ID 或对应推理接入点 ID。
- 固定 API 地址：`https://ark.cn-beijing.volces.com/api/v3/images/generations`。

本地启动时可先在 Bash 中安全输入密钥（不会显示输入内容）：

```bash
bash
read -s -p 'ARK_API_KEY: ' ARK_API_KEY
export ARK_API_KEY
export ARK_IMAGE_MODEL='替换为控制台的实际图片编辑模型ID'
.venv/bin/python app.py
```

本项目不自动读取 `.env`。云环境中请在环境设置中安全录入密钥，并设置模型 ID。界面只显示是否配置，不返回密钥或模型 ID。调用可能产生费用；仅在用户选择豆包并点击处理时发起，不自动重试或切换到付费 API。未配置、鉴权失败、超时等情况会给出明确错误，不会伪装为基础增强成功。

接口使用参考：[火山引擎官方 SDK 的图片编辑资源](https://github.com/volcengine/volcengine-python-sdk/blob/247c4aaacf0d18da7d13ca27b2d8b3a4030ac24f/volcenginesdkarkruntime/resources/images/images.py)。需要支持 `image`、`response_format=b64_json` 和指定输出尺寸的模型。输出比例与原图显著不符时停止处理；生成内容本身仍需人工核对。

## 图像处理与限制

- 默认去除全部同色背景，包括封闭图形内部同色底。
- 已有透明背景的图片保留透明度；背景颜色从图片边缘估计。
- 虚线或浅色文字消失时降低容差；细线较多时关闭降噪。
- 自动裁边保留选区内所有非背景内容，包括文字和题干；可以先框选排除不需要的内容。
- 棋盘格、白底只影响预览，输出 PNG 保留透明通道。
- 不支持复杂照片背景分割。最大上传 20 MB，基础模式原图 1200 万像素，放大后 2400 万像素。
- 本系统在内存中处理图片，不持久保存原图和结果；豆包 API 会发送图片给服务商，豆包 App 模式则通过客户端发送并可能保留在聊天记录中。

## 性能复测

```powershell
.\.venv\Scripts\python.exe benchmark.py
```

Mac / Linux 使用 `.venv/bin/python benchmark.py`。该命令对 440×334、1000×760、1000×1000 的几何示例图分别测试两次，最后一种使用 3 倍输出；每组首轮包含模型重新加载。测量完整 Flask 请求，包括模型推理、去背景、裁边、PNG/Base64/JSON 编码，不包含用户上传网络延迟与浏览器绘制。若任一次达到 10 秒，脚本返回非零状态。电脑性能、图像复杂度和降噪选项会影响速度，云端结果不能保证所有 Windows 电脑上的耗时。
